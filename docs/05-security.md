Direct response to the security analysis. Each flagged risk maps to a concrete control built
in the MVP (or an explicit deferral).

## The honesty rule (central anti-pattern fix)

The reference audit's worst finding was an LLM presenting fabricated data as real. We forbid
it structurally: every metric is either **measured** or carries an explicit `method`/`basis`
marking it an estimate.

- **Energy/carbon** — derived from **real** provider `usage` (tokens/images) × documented
  factors; `environmental_report.method = "model-factor-estimate"`, `basis` lists the factors.
- **Originality** — **real** intra-batch similarity only; stored as
  `{ method: "intra-batch-phash", checked_against: "this batch only", note: "external corpus deferred" }`.
  Never claims a web-wide check.
- **Quality score** — computed from real signals (finish reason + originality + validation
  pass) with `quality_score_method`; never `Math.random()`.

## Deferred (documented in `02-scale-vision.md`, with rationale)

- **SSRF / sandboxing of executed generated code** — the creative slice generates **images**,
  not executed code, so there is no code-execution surface in the MVP. When the **code** skill
  lands, its runner must execute generated code only in a network-restricted, read-only-FS
  sandbox (gVisor/Firecracker). Tracked as a hard prerequisite for that skill.
- External-corpus plagiarism, in-image OCR PII detection, KMS-based automated key rotation,
  gateway-grade rate limiting, mTLS between services — all scale-vision.

## Database linter status

After migrations 0008–0010 the critical `rls_disabled` finding is resolved (RLS on every
business table, proven by `supabase/tests/rls_idor_test.sql`). Remaining linter items are
deliberate or low-severity:

- `routing_embeddings` RLS-enabled-no-policy — **intentional**: server-side (service_role)
  access only; no client should read routing internals.
- `is_staff` callable by `authenticated` over RPC — **accepted**: RLS policies must be able to
  evaluate it, and it only returns a staff boolean. `anon` execute is revoked.
- `vector` / `pg_net` installed in `public` — **deferred** to scale-vision hardening:
  relocating an in-use extension type post-hoc is risky.

## LGPD lifecycle

- Sensitive columns enumerated in [`04-data-model.md`](04-data-model.md).
- Bases legais and data classification from the security plan apply (consent for prompts,
  legitimate interest for operational metadata, legal obligation for access logs).
- Retention: artifacts and prompts honor a retention window; soft-deleted tasks are
  hard-deleted by a cleanup job after the window. Logs containing PII get the shortest
  retention; non-PII operational logs may live longer.
- A data-subject erasure path (delete a user's tasks/artifacts/profile) is a documented
  follow-up endpoint, not in this first slice.
